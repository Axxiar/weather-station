# Weather Station

Small project to learn Arduino and MQTT.

:warning: This repo is not yet up to date with final report. 

## Specs

- DHT11 Sensor (Humidity + Temperature)
- 5528 Photoresitor (Luminosity)
- LCD 1602 (Data display)
- x2 UNO R4 Wifi
  - One for sensors and sending data
  - One for receiving and displaying on the LCD and a Webserver
